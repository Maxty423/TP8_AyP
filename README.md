## Formas de clonacion en IntelliJ

Hay dos formas de clonar este repositorio:

```bash
Desde la pantalla de bienvenida (inicio):

   1. Abre IntelliJ IDEA.
   2. Haz clic en Get from Version Control (o Clone Repository).
   3. Pega la URL que copiaste en el campo URL.
   4. Elige la carpeta de tu computadora donde quieres guardarlo en el campo Directory.
   5. Haz clic en Clone.

Con un proyecto ya abierto en IntelliJ:

   1. Ve al menú superior y selecciona Git > Clone... (o VCS > Git > Clone).
   2. Pega la URL del repositorio.
   3. Selecciona el directorio de destino.
   4. Haz clic en Clone.
```
